# Fonts

Used only by `layouts/_partials/og/card.html` to draw text on the social cards.
They are never served to visitors.

| File | Family | License |
|---|---|---|
| `Inter-Regular.ttf` | [Inter](https://github.com/rsms/inter) 4.1 | OFL 1.1 — `Inter-LICENSE.txt` |
| `Tinos-Bold.ttf` | [Tinos](https://github.com/googlefonts/tinos) | OFL 1.1 — `Tinos-OFL.txt` |

Tinos stands in for the Georgia the stylesheet asks for in headings: Georgia is
proprietary and cannot be redistributed here, and Tinos carries Times metrics,
which is the next font in that CSS stack.
